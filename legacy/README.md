# Legacy: EDI Multiple Sclerosis Detector

This directory holds a complete, earlier, **abandoned** project — a 2.5D `HybridMiniSwin2D5` MS-lesion segmentation webapp — that predates and is unrelated to the current NeuroScan 3D U-Net / BraTS research (see `../docs/`).

It is kept for historical reference only. Nothing here is imported by, or coupled to, any current NeuroScan code (verified: zero cross-references from `experiments/`, `Dataset/`, or the `neuroscan_3d_v*.py` architecture files).

See `WORKSPACE_ORGANIZATION.md` in this directory for that project's own (now-historical) structure description.

**Do not build on this code.** For current work, see the project root `README.md` and `docs/START_HERE.md`.
