3.2 INPUT PROCESSING (2.5D APPROACH)
------------------------------------
Input Dimensions:
- Original volume: (H, W, D, C) where C = 3 modalities (FLAIR, T1, T2)
- Typical size: (256, 256, 155, 3) after resampling

2.5D Slicing Strategy:
- Slice thickness: k = 5 consecutive slices
- For each target slice i, extract: [i-2, i-1, i, i+1, i+2]
- Reshape to: (H, W, k×C) = (256, 256, 15)
- Advantages over pure 3D:
  ✓ Preserves inter-slice context
  ✓ Reduces memory footprint
  ✓ Faster training (proven by ablation)
  ✓ Maintains spatial information

Rationale for 2.5D:
- Ablation study showed No3DConv variant performed BETTER (+2.36%)
- Confirms 2.5D approach superior to pure 3D for this task
- Balances between 2D (no context) and 3D (expensive)

3.4 ENCODER ARCHITECTURE
------------------------

Layer 1: Initial Convolution
- Conv3D: (k×C, 32, kernel=3, stride=1, padding=1)
- Input: (256, 256, 15)
- Output: (256, 256, 32)
- BatchNorm + ReLU + Dropout(0.3)

Layer 2: Downsampling Block 1
- Conv3D: (32, 64, kernel=3, stride=2, padding=1)
- Output: (128, 128, 64)
- MiniSwin Block (window_size=4, num_heads=4)
- Residual Connection

Layer 3: Downsampling Block 2
- Conv3D: (64, 128, kernel=3, stride=2, padding=1)
- Output: (64, 64, 128)
- MiniSwin Block (window_size=4, num_heads=8)
- Residual Connection

Layer 4: Downsampling Block 3
- Conv3D: (128, 256, kernel=3, stride=2, padding=1)
- Output: (32, 32, 256)
- MiniSwin Block (window_size=4, num_heads=16)
- Residual Connection

3.5 BOTTLENECK (ResNet Block)
------------------------------
ResNet Bottleneck with CSRF:
- Input: (32, 32, 256)
- ResNet Bottleneck: 3 convolutional layers with skip connection
  * Conv 1×1: 256 → 512
  * Conv 3×3: 512 → 512
  * Conv 1×1: 512 → 256
- CSRF Module: Channel and Spatial Refinement
  * Channel Attention: Global average pooling → FC → Sigmoid
  * Spatial Attention: Conv → Sigmoid
  * Output: Refined feature map
- Output: (32, 32, 256)

CSRF Module Details:
Channel Attention:
- Global Average Pooling: (32, 32, 256) → (1, 1, 256)
- FC Layer 1: 256 → 64 (reduction ratio = 4)
- ReLU
- FC Layer 2: 64 → 256
- Sigmoid
- Multiply with input features

Spatial Attention:
- Conv 7×7: 256 → 1
- Sigmoid
- Multiply with channel-refined features

Benefits:
✓ Emphasizes important channels
✓ Highlights relevant spatial locations
✓ Improves small lesion detection
✓ Reduces false positives

3.6 DECODER ARCHITECTURE
------------------------

Upsampling Block 1:
- TransposeConv3D: (256, 128, kernel=2, stride=2)
- Concatenate with encoder skip (64, 64, 128)
- Conv3D: (256, 128, kernel=3, padding=1)
- BatchNorm + ReLU + Dropout(0.3)
- Output: (64, 64, 128)

Upsampling Block 2:
- TransposeConv3D: (128, 64, kernel=2, stride=2)
- Concatenate with encoder skip (128, 128, 64)
- Conv3D: (128, 64, kernel=3, padding=1)
- BatchNorm + ReLU + Dropout(0.3)
- Output: (128, 128, 64)

Upsampling Block 3:
- TransposeConv3D: (64, 32, kernel=2, stride=2)
- Concatenate with encoder skip (256, 256, 32)
- Conv3D: (64, 32, kernel=3, padding=1)
- BatchNorm + ReLU + Dropout(0.3)
- Output: (256, 256, 32)

Final Layer:
- Conv3D: (32, 1, kernel=1)
- Sigmoid activation
- Output: (256, 256, 1) - binary segmentation mask

3.7 SKIP CONNECTIONS
--------------------
Type: Concatenation (U-Net style)

Connections:
1. Encoder Layer 1 (256, 256, 32) → Decoder Layer 3
2. Encoder Layer 2 (128, 128, 64) → Decoder Layer 2
3. Encoder Layer 3 (64, 64, 128) → Decoder Layer 1

Benefits:
✓ Preserves fine-grained details
✓ Helps gradient flow
✓ Improves small lesion detection
✓ Reduces vanishing gradients

Ablation Finding:

6.1 LOSS FUNCTION
-----------------

Loss: Focal Tversky Loss

Formula:
FTL = Σ (1 - TI) ^ γ
where TI = Tversky Index
TI = TP / (TP + α*FN + β*FP)

Parameters:
- α (FN weight): 0.7
- β (FP weight): 0.3
- γ (focal parameter): 1.33

Rationale:
✓ Addresses class imbalance
✓ Emphasizes hard examples (focal term)
✓ High α → prioritizes recall over precision
✓ Reduces false negatives (clinically critical)
✓ Better than Dice Loss for small lesions

Why Not Dice Loss?
- Dice Loss treats FN and FP equally
- Medical imaging needs high recall
- Missing lesions worse than false alarms
- Focal Tversky provides better control

Alternative Losses Considered:
- BCE + Dice: Unstable on class imbalance
- Focal Loss: Less control over FN/FP trade-off
- Weighted BCE: Requires manual weight tuning
- Conclusion: Focal Tversky superior for this task
