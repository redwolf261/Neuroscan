# NeuroScan Master Experiment Table

**Purpose**: This is the project's closing scientific artifact — a single, complete
accounting of every experimental phase (E1 through E203+), assembled by direct reading
of all phase documents (not from memory or prior summaries), following the project's
own standing discipline: read artifacts, not summaries; flag every self-correction the
project's own documents made; never fabricate a number that isn't in a source doc.

Built by parallel extraction across ~200 phase documents in `docs/phases/`, cross-checked
against the synthesis documents (`PHASE_RESEARCH_ARC_MASTER_REPORT.md`,
`PHASE_POST_E43_SUMMARY.md`, `RESEARCH_KNOWLEDGE_MAP.md`, `REPORT_RECOVERABILITY_FRONTIER.md`)
and this conversation's own directly-run experiments (E200, E201, E203).

**Column legend**: ΔDice is signed, percentage points, vs. the relevant baseline stated in
that row (baselines differ across the project's history — see notes). Verdict categories:
KILLED (clean negative) / KILLED (confound) / KILLED (bug-caused) / NULL (no effect) /
PASSED (sub-threshold, real effect) / SUPERSEDED (design step) / INCONCLUSIVE /
VALIDATED MEASUREMENT (not a Dice method) / CLOSED (audit only).

**Status**: IN PROGRESS — sections below are being added as parallel extraction batches
complete. Sections present so far are final; sections not yet present are pending.

**Arc 5 discrepancy flags — the MaxPool3d shared-tensor bug (full detail)**:
1. **E62/E63's bug, exact mechanism**: `forward_from_enc1()` used ONE `enc1` tensor for two roles — pool1's input AND the decoder skip-connection input (read again via attention gate and `cat1`). Both phases' derangement intervention reached BOTH paths simultaneously. An inline code comment falsely asserted "skip = enc1 -- reads the REAL, un-permuted enc1" — an UNVERIFIED claim. Since `MaxPool3d(2)` is mathematically, provably invariant to any within-cell derangement (max(x)=max(π(x))), the ENTIRE pool1→...→decoder computation graph was bit-identical between intact and "permuted" runs. 100% of E62's and E63's measured effects came through the skip path, not pooling.
2. **E64's fix and its own differential check** (verify pool1's output bit-identical under permutation; verify pool-only-permuted forward gives zero change; verify skip-only-permuted forward gives nonzero change) is now the project's standing discipline for any future dual-role-tensor intervention.
3. **Three different checkpoint lineages appear across E61-E84**: E62/E63 used v5/E46 (gated); E64 deliberately used BOTH v5 and v3 to separate gate-mediated effects; E65 onward standardized on v3/ungated (per E64's finding effect is not gate-dependent and is larger without the gate); E70 onward moved to the newer multimodal MM-seed0 (v3, 4-channel) checkpoint. These are not directly comparable without checking which checkpoint each phase used.
4. **E70-E71 "overnight" document reports CAS's seed-0 result (+0.30pp) as "suggestive but NOT confirmed" even before the 3-seed run** — the 3-seed confirmation in the SAME document then confirms the non-replication. Use the 3-seed number (+0.24pp, not confirmed), not the seed-0 number.
5. **Recurring pattern: auto-generated summary JSON fields sometimes give an incorrect "reading" that the prose then corrects.** This happens in E77 (JSON says outcome "A", prose corrects to "A/B overlap"), E80 (JSON defaults to a wrong hypothesis reading for negative recovery fractions, prose overrides), and E82 (JSON says "LOCAL EQUIVALENCE," prose corrects to "distance-graded, not flat"). Any downstream synthesis pulling raw JSON instead of markdown prose for these three phases would get the WRONG verdict.
6. **E71's "prediction 2" is a two-stage document**: original 200-label FAILED, later updated in the SAME document with a 1126-label re-test that PASSED (marginally). The final/current status is PASS, not FAIL — the superseded FAIL is preserved in the file but not the current verdict.

## Final summary

**Total experiments tabulated**: 203+ distinct phases/sub-phases across 8 arcs (Arc 0 through Arc 8), drawn from 197 phase documents plus this conversation's own 3 directly-run experiments (E200/E201/E203 as executed here, distinct from any same-numbered phase document).

**Verdict count** (approximate, by primary verdict category across all arcs):
- KILLED (clean negative / confound / bug-caused): ~85 rows — the large majority of all tested mechanisms
- NULL (no effect): ~15 rows
- SUPERSEDED (design step): ~30 rows
- CLOSED (audit only): ~20 rows
- INCONCLUSIVE: ~15 rows
- PASSED (sub-threshold, real effect): ~20 rows
- VALIDATED MEASUREMENT (not a Dice method): ~15 rows

**The single best validated result across the entire project**: **Deep Supervision, D4-only (Arc 2/3), +0.33 percentage points** (0.9096 vs canonical baseline 0.9063, per E27's audit reconstruction — E36's own mechanism-autopsy document does not independently restate these raw numbers, see Arc 3 Flag 1). Mechanistically explained (E36): D4 supplies real, non-converged gradient signal from boundary/partial-coverage geometry into shared early layers, late in training, when the main task's signal has already narrowed to fine local polishing. This is a **geometric coarsening effect, not primarily a lesion-size effect.** None of the 6 pairwise comparisons among the D4/D2/Both/baseline conditions reached statistical significance at n=125 (all p>0.07) — real, mechanistically grounded, but not statistically bulletproof at this sample size.

**No mechanism tested after D4 reliably beat it.** The two mechanisms that appeared to exceed D4's threshold on single-seed evidence (E45 D4+D8, E54 A96) both fell to statistically indistinguishable margins under proper 3-seed confirmation — the project's central, load-bearing methodological finding (Arc 4).

**Closure statement**:

> Across the experimentally investigated mechanism classes, no tested intervention produced a defensible ≥1 percentage-point improvement over the fixed v5 control, and the final recoverability-guided mechanism was rejected before implementation because its required exploitable population was absent and its subject-level arithmetic ceiling was only +0.272 pp.
